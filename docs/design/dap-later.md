# DAP (Debug Adapter Protocol) — later phase

**DAP** (breakpoints, stepping, variable view) is planned for a **later phase**. Asili does not currently implement a DAP server.

See [docs/design/implementation-status.md](implementation-status.md) for where this sits relative
to other work — it's a real, sizeable chunk of work (adapter, launch config, integration with the
evaluator), but not a production-readiness blocker the way CI or test coverage is.

Documentation only; no implementation exists yet.

# DAP (Debug Adapter Protocol) — later phase

**DAP** (breakpoints, stepping, variable view) is planned for a **later phase**. Asili does not currently implement a DAP server.

See comparison doc item 1: [docs/nuru-comparison.md](../nuru-comparison.md) — Nuru has `cmd/nuru-dap` and tooling docs; Asili’s equivalent would be a separate, sizeable chunk of work (adapter, launch config, integration with evaluator/VM).

No implementation in the current Nuru-comparison application plan; documentation only.

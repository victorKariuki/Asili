# Hisabati (math) — REPL help

**Moduli:** `leta hisabati`

## Kazi za kawaida

- `jumla(a, b)` — jumla ya namba
- `tofauti(a, b)` — tofauti
- `zao(a, b)` — zao
- `gawio(a, b)` — gawio (Tokeo; kosa ikiwa b = 0)
- `duara(n)` — duara
- `absolute(n)` — thamani kamili
- `kipeo(n, p)` — n ** p (Tokeo)
- `mizizi(n)` — mizizi ya mraba (Tokeo; n >= 0)

## Mfano

```
> leta hisabati
> weka j = jumla(2, 3)
> j
Namba(5.0)
```

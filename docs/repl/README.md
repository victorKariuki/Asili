| Topic   | File           | Description        |
|---------|----------------|--------------------|
| hisabati| hisabati.md    | Math module        |
| orodha  | orodha.md      | List construction  |
| kazi    | kazi.md        | Functions in REPL   |

Path: `docs/repl/{topic}.md` (configurable). Discovery: fixed list in code or scan `docs/repl/*.md`.
